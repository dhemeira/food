# Concept changes

Applied to `docs/home-concept.html` on 2026-11-15.

## Second pass

1. Ingredients and step copy use `text-wrap: pretty`.
2. Mobile steps stack the instruction under the number.
3. Detail hero gets an explicit width so the `min-height` + aspect-ratio combination no longer stretches it to 625px on mobile; this restores the share button and Főzve counter. Detail footer buttons stay clear of the fixed tab bar; the theme switch moved out of the detail footer.
4. Theme switch moved to the page footer and extended to three palettes: Indigó / Terrakotta / Zsálya.
5. Indigo softened to a muted lavender accent on warm charcoal surfaces.
6. Third palette added: muted sage (Zsálya).
7. Recipe card images now carry the detail hero's bottom shade; the card box-shadow experiment was removed.

Open items: the UX/UI polish recommendations from the design review are not implemented yet.
